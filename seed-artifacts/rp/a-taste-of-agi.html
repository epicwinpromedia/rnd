Abstract

Stripping away keynote hype, what actually differentiates a genuinely useful agentic system from an impressive demo? Through primary-source forensics, we show that durable agentic workflows depend on standard tool contracts (MCP + WebMCP), sandboxed execution, and machine-readable web infrastructure.

KEY RECEIPT

Combining server-side EmDash MCP, browser-side WebMCP (document.modelContext), and R2 Markdown negotiation turns any publication into a verifiable agentic surface.

1. Beyond the Demo Reel

Spectacle demos succeed in controlled videos and fail on real enterprise workflows because they rely on fragile DOM scraping and unguarded permissions. Real capability requires explicit tool schemas, read-only vs. consequential annotations, and clean failure recovery.

2. The Three-Layer Agentic Stack

Production agentic readiness spans three interlocking layers: (1) Server MCP for structured backend queries with Zero Trust write protection, (2) Browser WebMCP for in-tab state transitions, and (3) Content-negotiated Markdown for Agents so crawlers and assistants consume clean prose at the edge.

3. Trust as the Ultimate Moat

As inference becomes a commodity, trust—cryptographic, architectural, and editorial—becomes the moat. Organizations that pair open standards with verifiable infrastructure win both the developer mindshare and the enterprise boardroom.
